
# BioSpoil AI

BioSpoil AI is a machine learning prototype
for classifying food quality using environmental parameters.

## Supported Fruits
- Banana
- Orange
- Pineapple
- Tomato

## Model
Random Forest Classifier

## Features
- Temperature
- Humidity
- Light
- CO2

## Disclaimer
This is a research prototype, not a certified food
safety or microbial spoilage detection system.
